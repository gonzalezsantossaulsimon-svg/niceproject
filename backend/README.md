# NiceProject — Sistema de Gestión de Profesores y Academias

Proyecto para la materia de Desarrollo Rápido de Aplicaciones.

## 🛠️ Tecnologías

- **Backend:** Node.js + Express
- **Frontend:** HTML + W3.CSS + JavaScript (módulos ES6)
- **Datos:** Archivo `db.json` (simula base de datos)
- **Autenticación:** Login simple con localStorage
