# NiceProject — Sistema de Gestión de Profesores y Academias

Proyecto para la materia de Desarrollo Rápido de Aplicaciones.

## 🛠️ Tecnologías

- **Backend:** Node.js + Express
- **Frontend:** HTML + W3.CSS + JavaScript (módulos ES6)
- **Datos:** Archivo `db.json` (simula base de datos)
- **Autenticación:** Login simple con localStorage

## 🎯 Objetivo del proyecto

Desarrollar un sistema universitario para la gestión de profesores y academias, permitiendo administrar información académica y profesional de los docentes, así como las materias y academias relacionadas con cada profesor.

El sistema servirá como base para incorporar posteriormente funcionalidades adicionales, como validaciones, gestión de usuarios y evaluación de profesores.

## ▶️ Ejecución del proyecto

Para instalar las dependencias del backend:

```bash
cd backend
npm install
```

Para iniciar el servidor:

```bash
npm start
```

El backend se ejecuta en:

```text
http://localhost:3000
```

El frontend puede abrirse utilizando Live Server desde Visual Studio Code.
